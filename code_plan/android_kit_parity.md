## 글꼴 원인 분리
- 앱 글꼴 체인은 Roboto, Noto Sans KR, system-ui, Pretendard GOV Variable 순이다. 이 컴퓨터에서 Roboto와 Noto Sans KR가 모두 설치되어 있고(캔버스 폭 측정으로 구분, document.fonts.check 는 설치 여부와 무관하게 true 가 나와 쓰지 않음) 영문과 숫자는 Roboto, 한글은 Noto Sans KR로 그려진다. Pretendard 는 체인 끝이라 쓰이지 않는다.
- 피그마는 Pretendard 였고 같은 문장 폭이 약 5% 좁아(예 훈련 발령으로 명단 확인 139.2 대 132) 가운데 정렬 글자가 3~7px 어긋났다. 글꼴을 Roboto, Noto Sans KR로 바꾸고 글상자를 앱 실측 상자에 맞춘 뒤 글상자 위치 어긋남은 0.5px 안(평균 낸 값이 아니라 최대값)이다.
- 남는 차이: 글자 안 모양이 약 2px 아래로 보인다. 브라우저는 줄 높이를 Roboto 기준으로 잡고 한글 글리프를 같은 기준선에 놓고, 피그마는 한글만 있는 줄을 Noto 기준으로 놓아서 생기는 차이로 보이며 글상자 값으로는 재지지 않는다.

## 816 가로 어긋남 원인
앱은 폭 720 이상에서 CSS 다단(column-count 2)으로 두 열을 만든다. 하네스 빌더는 다단을 한 열로 세로 쌓아 두 번째 열 카드가 첫 열 높이만큼(최대 280px) 아래로 갔다. 추출 전에 두 열을 열 묶음 상자로 바꿔(위치 변화 0px 확인) 다시 전사했다.

## 시간에 따라 바뀌는 값
산불위험지수 최고와 평균, 도착 마감 시각, 도우미 응답 수는 앱이 열 때마다 달라진다. 대조에서 문구 불일치로 잡힌 것은 이것뿐이다.

## 아직 남은 것
- 글자 스타일 type/* 연결 0 (type/* 는 Pretendard GOV 스타일이라 Roboto, Noto Sans KR 글자와 같은 스타일이 없음)
- 채움 색 #9CA3AF 4개 연결 못 함(같은 값의 변수가 없음, 검색 자리표시 글자색)
- 글상자는 맞지만 글자 모양은 약 2px 차이
- 대화상자, 시트, 스낵바는 피그마 변형이 없음
