## 추정 규칙(동해시와 같은 순서)

- 재가 장기요양 수급자 = 2025 급여이용수급자 2,193명 - 노인요양시설 527명 - 노인요양공동생활가정 19명 = 1,647명. 등급별 값은 같은 방식으로 빼고 합계에 맞춰 나눴다(1등급 86, 2등급 156, 3등급 554, 4등급 737, 5등급 104, 인지지원 10).
- 행정동 배분은 75세 이상 인구 비율. 원덕읍임원출장소 인구는 원덕읍에 더했다(행정동 경계 자료에 출장소 경계 없음).
- 마을 배분은 건축HUB 법정동 건축물 통계를 받지 못해 동해시 스크립트의 대체 규칙인 경로당 수 비례(경로당 없는 마을 0.5개)를 썼다.
- 경로당 자료에 지번주소가 없어 시설명의 마을 이름(예: 늑구1리 경로당은 늑구리)으로 마을을 찾았고(170곳), 이름으로 못 찾은 70곳(아파트 경로당, 통 경로당 등)은 같은 행정동 안 가장 가까운 마을 기준점의 마을로 두었다.
- 동 지역 법정동의 행정동은 삼척시청 행정구역 표의 법정동 수(남양 5, 성내 15, 교동 5, 정라 2)와 OpenStreetMap 기준점의 경계 포함 여부로 정했다. 읍중동 기준점은 남양동 경계에 걸려 표의 수에 맞춰 성내동에 두었다.
- 이송 등급 대응(가정)은 동해시와 같다.
- 개인 단위 자료는 없다. 대상자 개인은 seed.js 가 위 수치에 맞춰 가상으로 만든다.
