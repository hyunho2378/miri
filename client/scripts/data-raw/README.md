## 추정 규칙

- 재가 장기요양 수급자 = 2025 급여이용수급자 2,668명 - 노인요양시설 646명 - 노인요양공동생활가정 17명 = 2,005명. 등급별 값은 같은 방식으로 빼고 합계에 맞춰 나눴다.
- 행정동 배분은 75세 이상 인구 비율, 법정동 배분은 단독주택 동수 + 공동주택 연면적 ÷ 100㎡. 행정동 안 법정동 하나라도 건축물 통계가 없으면 그 행정동은 경로당 수 비례로 나눈다.
- 이송 등급 대응(가정): 1등급 침상, 2등급 휠체어, 3등급과 4등급 부축, 5등급과 인지지원등급 도보(치매 인솔). 근거는 노인장기요양보험법 시행령 제7조 등급 정의.
- 개인 단위 자료는 없다. 대상자 개인은 seed.js 가 위 수치에 맞춰 가상으로 만든다.
