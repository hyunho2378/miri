TEAM 오아시스 / 미리 서비스 도식 3

데이터 흐름도

종이 대피계획서에서 시작한 정보가 명부, 부족분 계산, 배정, 도우미 보고, 소방 인계, 기록으로 이어지는 경로와 각 단계에서 개인정보가 머무는 위치를 정리한 도식입니다.

시제품은 전 구간 가상 데이터. 실제 주민 정보는 저장하지 않음
처리 주체 AI멀티모달 LLM 판독 규칙고정 공식과 탐색 규칙 사람 확인담당자 또는 시 관리자 확정 개인정보 위치 실명 포함원본. 지자체와 시설에만 보관 비식별대상자 코드, 마을, 등급, 태그만 기간 한정발령 기간에만 표시, 종료 시 삭제
지자체와 시설 실명 포함
원본 서류와 명부 보관. 미리로 원본을 옮기지 않음
미리 (담당자 콘솔과 서버) 비식별
대상자 코드, 동, 마을, 이송 등급, 특이사항 태그만 저장. 이름 열 없음
도우미 휴대폰
기간 한정 본인 담당 대상자만 표시
외부 기관
공공데이터는 개인정보 없음. 소방은 인계 목록만 받음
평시
발령
1종이 대피계획서
대피카드 포함. 시설과 재가기관이 작성. 사진, 스캔, PDF
실명 포함
지자체 명부 원본
지자체 서버 보관. 이름을 뺀 코드만 미리 명부와 연결
2서류 읽기
AI전사, 이송 등급 판정, 근거 문구
규칙원문 대조, 불일치 시 신뢰도 하향
사람 확인담당자 확인, 수정, 제외
판독 결과에 이름, 주소, 전화번호를 출력하지 않음
3대상자 명부
대상자 코드, 동, 마을, 이송 등급, 특이사항 태그, 판정 출처, 확인 상태
차량과 도우미
협약 차량(차종, 정원), 도우미 명단. 모집은 설문 /f/:id
4부족분 계산 규칙
이송 가능 인원 = 차량 수 × 왕복 가능 횟수 × 정원
왕복 가능 횟수 = (기한 8시간 − 준비 1시간) ÷ 왕복 시간
출력: 마을별 부족분, 필요 추가 차량
계산 조건
준비 시간, 이송 기한, 마을별 왕복 시간, 도달 가정 시나리오
차종별 정원과 등급 호환은 가정값
5상황판과 현황판
미이송 예상, 부족 마을, 필요 추가 차량. 지도의 마을 좌표는 가상
공공데이터포털
산불 위험, 대피소, 장기요양기관
발령 개시 (시 관리자 확인)산림청 도달 예측 시각에서 8시간 역산, 마을별 발령 기한
6추천 배정
규칙침상 우선 기본 순서에서 지역 탐색
사람 확인담당자 배정 확정
7도우미 화면
/h/:token. 배정 요약, 수락 또는 불가. 종료 시 삭제
8완료 보고
출발, 도착, 탑승, 인계 단계. 실패 보고
9발령 운영 현황
규칙진행 집계, 점검: 기한 초과 예상, 무응답
10소방 인계
동해소방서. 미이송자 목록 수신 사람 확인
11기록
이송 기록 저장, 도우미 화면 정보 삭제. 다음 협약 규모 산정 근거
확인 완료 항목
등급별 인원
마을별 부족분
위험 지수, 시설 위치
배정 링크 (본인 건만)
단계 보고, 실패 보고
실패 건 재배정
미이송자 목록
이송 결과
