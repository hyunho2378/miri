## 1. 원칙
- 피그마에서 바꾸면 같은 차례에 코드도 같은 이름과 값으로 바꾼다. 코드에서 바꾸면 피그마도 바꾼다. 한쪽만 바뀐 상태로 두지 않는다.
- 피그마 변수 이름 = 코드 `tokens.js` 키 경로. 피그마 부품 이름 = React 부품 경로. 화면 번호 = `code_plan/screens.json`.
- 깃허브 main 이 코드 기준이다. 피그마 쪽 변경 기록은 `figma_progress.md`, 코드 쪽 변경은 커밋 메시지에 같은 화면 번호를 적는다.
- 피그마, 로컬, 깃허브 세 곳이 다른 상태는 보고에 반드시 적는다.
