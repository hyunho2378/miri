# 미리: 재난취약자 사전 이송 배정

재난취약자를 대피 기한 안에 옮길 차와 사람이 몇 명분 부족한지 평시에 계산하고, 대피 발령 시 차량과 도우미와 대상자를 묶어 배정하는 읍면동 재난 담당자용 웹 서비스다.

- 서비스: https://miri-indol.vercel.app (가상 데이터로 시연, 로그인 없이 담당자 화면이 열린다)
- 사례 소개: https://miri-case.vercel.app
- 만든 곳: 한림대학교 서비스디자인 2026-2 Team 오아시스(주현호, 허준희, 김서환, 김채린, 김민준). 공모전 출품은 주현호, 송준하

> [!CAUTION]
> 시연용이다. 대상자 개인과 차량은 가상이고, 마을과 대피소, 건물, 인구, 장기요양 통계는 실제 공개 자료다. 부족분은 규칙 기반 계산값이며 실제 대피 판단의 단일 근거로 쓰지 않는다. 동해시 담당자 검증은 진행 예정이다.

## 1. 작품 개요

| 항목 | 내용 |
| --- | --- |
| 작품명 | 미리: 재난취약자 사전 이송 배정 서비스. 미리 계산하고 미리 옮긴다는 원칙을 이름에 담았다 |
| 사회 현안 | 산불과 대설, 극한호우 때 재난취약자 대피 실패. 연계 현안은 초고령화와 지역소멸 |
| 주 사용자 | 읍면동 재난 담당자. 보조 사용자는 대피 도우미와 요양시설 관리자 |
| 대상자 | 재난취약자 본인은 설치하거나 조작할 것이 없다 |
| 정책 근거 | 행정안전부 「초고속 산불 대비 주민대피 체계 개선방안」(2025. 4. 16.). 위험구역 5시간 전 대피와 재난취약자 8시간 전 대피 체계를 지자체에 제시 |
| 시범 지역 | 동해시. 2022년 강릉 옥계 산불이 동해시 망상동까지 번진 이력이 있다 |

핵심 기능은 세 가지다.

- **부족분 계산**: 도달 시각 안에 옮기지 못하는 인원을 마을별 숫자로 표시한다. 봄철 산불 조심 기간 전 차량 협약 규모를 정하는 근거가 된다.
- **도달 시각 역산**: 산불 확산 가정에서 마을별 도달 시각을 구하고, 거기서 이송 기한과 발령 기한을 거꾸로 계산한다.
- **배정표**: 발령 시 차량과 도우미와 대상자를 묶어 도우미 휴대폰으로 보낸다.

## 2. 문제 인식

재난 알림 체계는 갖춰졌으나 이송 체계는 비어 있다. 재난문자와 안전디딤돌은 걸을 수 있는 사람의 자력 대피를 전제로 하고, 거동이 불편한 사람은 알림을 받아도 차와 사람이 도착해야 대피할 수 있다. 정해진 시간 안에 차와 사람이 충분한지 계산하는 도구가 없다.

| 근거 수치 | 값 | 시점과 출처 |
| --- | --- | --- |
| 영남 산불 대피 과정 사망 | 31명, 60대 이상 28명(90.3%) | 2025. 3. 중앙재난안전대책본부 |
| 스스로 준비할 수 없어 대피를 포기한 비율 | 57.7% | 2026. 9. 2. 국립재난안전연구원 |
| 복지시설 긴급 전원 | 52개 기관 1,458명 | 2025. 3. 보건복지부 |
| 울진 삼척 산불 대피 | 35개 마을 6,482명 | 2022. 3. 행정안전부 재난연보 |
| 동해시 주민등록인구와 65세 이상 | 85,445명 중 23,590명 | 2026년 9월, 행정안전부(KOSIS DT_1B04005N) |
| 동해시 재가 장기요양 수급자 추정 | 2,005명 | 2025년 급여이용수급자 2,668명에서 시설급여 663명을 뺌, 국민건강보험공단(KOSIS) |

유사 서비스와의 차이는 다음과 같다.

| 구분 | 기존 서비스 | 하지 않는 일 |
| --- | --- | --- |
| 알림 | 재난문자, 안전디딤돌, 홍수알리미 | 거동 불편자 이송 |
| 종이 계획 | 산불 취약 특수보호시설 대피계획 가이드라인 | 재가 거주자 포함과 차량 부족 계산 |
| 사람 지정 | 제주 대피 도우미, 충남 안전 파트너 | 정해진 시간 안 이송 가능 여부 판단 |
| 자원 관리 | 재난관리자원 통합관리시스템(KRMS) | 취약자 개인별 차량 배정 |
| 해외 상용 | 일본 NEC 피난 행동 지원 서비스(2024. 2.) | 시간 제약 계산과 부족분 산정 |

## 3. 화면과 기능

담당자 화면은 왼쪽 아이콘 줄(담당 업무, 기록과 설정, 공개 화면)과 두 번째 메뉴 칸, 흰 본문으로 나뉜다.

| 화면 | 주소 | 하는 일 |
| --- | --- | --- |
| 현황판 | `/console` | 미이송 예상, 마을별 미이송 막대, 확인할 일, 부족 상위 마을, 오늘 산불 여건(산림청, 기상청 실시간), 가용 차량 |
| 서류 읽기 | `/console/intake` | 종이 대피계획서와 대피카드 사진에서 이송 등급 초안과 근거 문구를 뽑고 담당자가 원문과 대조해 확인 |
| 대상자 명부 | `/console/roster` | 목록, 지도, 서식 출력. 이름 없이 대상자 코드로 표시 |
| 상황판 | `/console/map` | 3D 지형과 건물 196,111동 위에 산불 확산 가정, 마을별 대기 인원, 임시주거시설. 시간 축으로 발령 후 경과를 재생 |
| 차량과 도우미 | `/console/resources` | 차량 42대, 도우미 88명 가용 상태와 협약 만료 |
| 발령 준비 | `/console/shortage`, `/console/dispatch`, `/console/handover` | 부족분 계산, 훈련 발령과 배정 검토, 미이송자 소방 인계 |
| 문서함 | `/console/workspace` | 기관 협조 요청서, 훈련 결과 보고서 같은 한글(HWPX) 문서 작성. 본문 속 법령 인용을 법제처 자료로 확인 |
| 도우미 화면 | `/h/demo` | 도우미 휴대폰. 배정 수락, 출발, 탑승, 도착 단계 |
| 개방 API | `/open` | 마을별 부족분과 대피소 수용 현황 공개 조회 |

### 3D 상황판

- **범위**: 동해시와 맞닿은 강릉시(옥계면 포함), 삼척시, 정선군, 태백시까지 읍면동 60곳.
- **지형**: 읍면동마다 실제 고도로 만든 지형 조각이다. 조각을 바깥으로 벌려 볼 수 있다.
- **건물**: 국토교통부 GIS건물통합정보 196,111동을 대장 높이 또는 층수로 세운다.
- **바탕 지도**: 도로와 물길, 건물 바닥을 바탕에 직접 그렸다. 시군, 읍면, 리 이름과 300m 이상 산봉우리, 시청과 소방서와 병원 이름을 카메라 거리에 따라 겹치지 않게 보여 준다.
- **대피 대상 마을**: 집결지 둘레 원의 크기는 선택한 시점의 대기 인원이다. 원 중심 550m 안 건물은 그 마을의 부족 단계 색으로 칠한다. 대상자의 실제 거주 위치를 뜻하지 않는다.
- **산불 확산 가정**: 지형을 덮는 반투명 띠와 화살표, 발화 지점에서 퍼지는 고리로 보여 준다.
- **보기 전환**: 기본 보기는 3D다. 2D 지도(MapLibre)로 바꿀 수 있다.

## 4. 계산 규칙

부족분은 대상자 수에서 기한 안 이송 가능 인원을 뺀 값이다. 이송 가능 인원은 차량 수에 왕복 가능 횟수를 곱한 값이고, 왕복 가능 횟수는 준비 시간을 뺀 남은 시간을 왕복 시간으로 나눈 값이다.

| 이송 등급 | 대상 | 필요 차량과 인력 |
| --- | --- | --- |
| 도보 | 안내만 받으면 스스로 이동 | 마을 버스나 승용차와 인솔 1명 |
| 부축 | 부축을 받으면 승용차 탑승 가능 | 승용차와 도우미 1명 |
| 휠체어 | 휠체어에 앉은 채로 이동 | 리프트 승합차와 도우미 2명 |
| 침상 | 누운 상태로만 이송 가능 | 구급차나 침상 승합차와 구급대원 |

- 배정 순서: 이송 난도가 높은 침상부터 도보 순으로, 같은 등급 안에서는 도달 시각이 빠른 마을부터.
- 왕복 시간: 마을 집결지에서 임시주거시설까지 OSRM 도로 주행 시간 x 2 + 탑승과 하차 시간(기본 20분).
- 추천 배정: 기본 순서보다 미이송이 줄어드는 배정을 규칙 기반 탐색으로 찾는다. 기본 시나리오에서 기본 순서 300명이 추천 배정 285명이 된다.
- 계산은 `client/src/lib/shortageCalc.js`, 시험은 `client/tests/logic.test.mjs`(9개).

등급 대응(장기요양 1등급 침상, 2등급 휠체어, 3와 4등급 부축, 5등급과 인지지원등급 도보)은 팀 가정이다. 현장 검증 전이다.

## 5. AI 사용 범위와 공공 AX

AI는 계산을 대신하지 않는다. 부족분과 배정은 규칙으로 계산하고, AI는 사람이 하던 반복 업무 가운데 결과를 원문과 대조할 수 있는 단계에만 쓴다.

| 단계 | 쓰는 것 | 사람이 하는 확인 |
| --- | --- | --- |
| 서류 읽기 | Gemini 2.5 Flash(`client/api/intake.js`)가 종이 대피계획서의 거동 상태 문구에서 이송 등급 초안과 근거 문구를 뽑음 | 근거 문구가 서류 원문에 실제로 있는지 자동 대조(원문 일치, 불일치 표시) 뒤 담당자가 확인, 수정, 제외 |
| 문서 작성 | kordoc(광진구 류승인 주무관 공개)으로 한글 HWPX 서식을 읽고 채움 | 담당자가 본문 확인 뒤 내려받음 |
| 법령 인용 확인 | korean-law-mcp(광진구 류승인 주무관 공개)의 인용 검증 도구로 「법령명」 제N조가 실제로 있는지 확인(`client/api/law.js`) | 없는 조문은 표시만 하고 고치지 않음 |

행정안전부 「AI 정부 실험실」(2026. 7. 3. 시범운영)은 공무원이 AI 코딩 도구로 현장 업무를 직접 개선하고 결과물을 공공 개발산출물 저장소(gitlab.aigov.go.kr)로 공유하는 체계다. 같은 보도자료에서 예고한 「공공 AX 업무 지침」은 과제 발굴, 개발 환경 이용, 보안 준수, 품질 검증, 개발산출물 등록, 활용과 확산을 다룬다. 이 저장소는 그 순서에 맞춰 다음을 갖춘다.

| 지침 단계 | 이 저장소에서 |
| --- | --- |
| 과제 발굴 | 2. 문제 인식, `docs/PRD-v2.md` |
| 개발 환경 | 서버 없이 프론트에서 계산하는 정적 배포. 클라우드 키 없이 시연 가능 |
| 보안 준수 | 8. 개인정보 설계. AI에는 이름과 연락처를 보내지 않는다 |
| 품질 검증 | 계산 규칙 시험 9개, 원문 대조, 법령 인용 확인 |
| 개발산출물 | 코드, 자료 재현 스크립트(`client/scripts`, `tools/`), 출처 표 |
| 활용과 확산 | 시군구 코드만 바꿔 다른 지역 자료를 굽는 스크립트, 개방 API |

공공 저장소에서 참고한 공개 산출물은 다음과 같다.

- kordoc, korean-law-mcp, archhub-mcp(서울특별시 광진구 류승인): 한글 문서, 법령, 건축물대장. MIT
- 표준주소실록 gjdong(같은 작성자)의 제설 상황실: 건물 자료를 국토교통부 GIS건물통합정보로 쓰는 방법
- STAY UP 현장 상황판(완주소방서 김무영): 검증 상태를 맨 위에 밝히는 방식, 판정 표시에 색과 모양을 같이 쓰는 방식. Apache-2.0

## 7. 3D 상황판 만드는 법

모든 자료는 미리 구워 정적 파일로 둔다. 화면을 열 때 외부 지도 서버에 의존하지 않는다.

| 파일 | 만드는 법 | 크기 |
| --- | --- | --- |
| `client/src/mock/geoRegion.js` | admdongkor 경계에서 시군 코드 51170, 51150, 51230, 51770, 51190 읍면동을 골라 단순화 | 약 150KB |
| `client/public/terrain/region-dem.png` | AWS Terrain Tiles z11을 경위도 격자로 다시 뽑음. 픽셀 R x 256 + G 가 고도의 10배 | 1.3MB |
| `client/public/terrain/basemap-*.webp` | `tools/bake-basemap/bake.js`. OpenFreeMap 벡터 타일을 KRDS 회색과 파랑으로 다시 그림(광역 z12, 동해시 z14) | 1.4MB |
| `client/src/mock/geoPlaces.js` | 같은 스크립트가 지명, 산봉우리, 주요 시설을 뽑음 | 46KB |
| `client/public/terrain/buildings-nsdi.bin` | `tools/bake-buildings/extract.cjs`. 브이월드 GIS건물통합정보 강원 SHP에서 5개 시군만 골라 EPSG:5186을 경위도로 바꿈 | 5.6MB(전송 3.3MB) |

화면에서는 three.js가 그린다. Web Worker가 읍면동 경계를 델로네 삼각분할(Delaunator, Constrainautor)로 지형 조각을 만들고, 건물 윤곽을 earcut으로 지붕을 막아 세운다. 건물은 윗고리와 아랫고리만 두고 면 방향 음영을 화면에서 계산해 196,111동을 약 3초 안에 띄운다.

다른 시군에 쓰려면 시군 코드와 범위를 바꿔 세 스크립트를 다시 돌린다.

## 8. 개인정보 설계

- 명부 원본은 지자체 서버에 둔다. 클라우드에는 이름을 뺀 이송 등급과 마을 코드만 둔다.
- 도우미 휴대폰에는 본인 담당 대상자만 발령 기간에 보이고 종료 시 지운다.
- 서류 읽기는 이름과 연락처를 읽지 않는다. AI에 보내는 값은 거동 상태 문구뿐이다.
- 근거 조항(기획서 기준): 재난안전법 제31조의2와 제40조(안전취약계층 대피 지원), 노인장기요양보험법 제53조의2와 재난안전법 제74조의2(장기요양 정보 수급), 재난안전법 제74조의3과 개인정보보호법 제18조제2항(재난 시 정보 제공).

## 9. 실행과 배포

```bash
cd client
npm install
npm run dev        # http://localhost:5173
npm run build
node tests/logic.test.mjs
```

- `VITE_USE_MOCK=true`면 가상 데이터로 동작한다. 계산은 서버 없이 프론트에서 한다.
- 환경 변수(Vercel 서버에만 둔다. 화면 코드에 노출하지 않는다)

| 변수 | 쓰는 곳 | 없을 때 |
| --- | --- | --- |
| `GEMINI_API_KEY` | 새로 올린 서류 판독(`api/intake.js`) | 판독 서버 미연결로 안내. 미리 들어 있는 시연 서류로 확인 흐름은 볼 수 있다 |
| `DATA_GO_KR_KEY` | 산림청 산불위험지수, 기상청 특보와 예보 중계(`api/opendata.js`) | 오늘 산불 여건에 불러오지 못한 이유를 표시 |
| `LAW_OC` | 법령 인용 확인(`api/law.js`). 법제처 Open API 키 | 공개 korean-law-mcp 서버 기본값으로 동작 |
| `UPSTASH_REDIS_REST_URL`, `UPSTASH_REDIS_REST_TOKEN` | 문서함 저장(`api/workspace.js`) | 브라우저 저장소만 사용 |
- 배포: Vercel 프로젝트 두 개. 서비스는 `client/`, 사례 소개는 `case/`.

## 10. 저장소 구조

```text
client/            서비스(React 18, Vite, Tailwind, three.js, MapLibre)
  api/             Vercel 서버리스(서류 판독, 공공 API 중계, 법령 인용 확인, HWPX)
  src/three/       3D 상황판(지형 조각, 건물, 바탕 지도, 지명)
  src/lib/         부족분 계산, 배정, 이상 탐지(순수 함수)
  src/mock/        공개 자료로 만든 정적 데이터와 가상 데이터
  scripts/         동해시 공개 자료를 정적 데이터로 굽는 스크립트와 원본
  public/terrain/  지형, 바탕 지도, 건물 파일
case/              사례 소개 사이트(디자인 과정, 화면 설명)
tools/             3D 바탕 지도와 건물 굽는 스크립트
docs/              PRD, 정보 구조, 디자인, 화면 경로, API 계약, 원문 인용
server/            백엔드 자리(계약은 docs/API_CONTRACT.md)
```
