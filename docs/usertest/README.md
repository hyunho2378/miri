| 파일 | 용도 |
| --- | --- |
| 미리_청년공간열림_포스터_A4, SNS정사각 (html, png, pdf) | 동해 청년공간 열림 체험 모집 포스터, QR `https://miri-indol.vercel.app/h/demo` |
| 미리_한림봉사센터_학생체험_안내문 (hwpx, pdf, md) | 한림봉사센터 학생 20분 과제형 체험 안내 |
| 미리_사용자체험_진행표 | 진행 대본, 과제 안내 문장, 성공 기준, 관찰 항목 |
| 미리_사용자체험_기록지 | 과제별 성공 여부, 소요 시간, 막힌 지점, 발화 |
| 미리_사용자체험_만족도설문 | SUS 10문항(Brooke 1996, 팀 번역), 추가 문항 3개 |
| 미리_사용자체험_참여동의서 | 참여 번호 기반, 녹음과 화면 기록과 인용 선택 동의 |
| 미리_사용자체험_결과집계.xlsx | 과제 성공률, 평균과 중앙 소요 시간, SUS 점수 자동 계산 |
| img/, font/ | 포스터 HTML용 화면 캡처와 글꼴 |
