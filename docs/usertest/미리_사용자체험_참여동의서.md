## 1. 체험 목적

- 한림대학교 서비스디자인 수업 Team 오아시스가 만드는 재난 이송 배정 서비스 미리의 화면이 쓰기 쉬운지 확인하고 고칠 점을 찾음

## 2. 수집하는 것과 수집하지 않는 것

| 구분 | 내용 |
|---|---|
| 수집함 | 참여 번호, 참여 유형, 연령대(선택), 과제 성공 여부, 걸린 시간, 막힌 곳, 체험 중 한 말, 설문 응답 |
| 선택 수집 | 녹음, 화면 기록(아래에서 고른 경우만) |
| 수집하지 않음 | 이름, 연락처, 학번, 주소, 얼굴 사진 |

- 서명란의 이름은 동의 확인용으로만 쓰고 기록지와 집계표에는 옮기지 않음
- 화면 속 대상자와 차량은 모두 연습용 자료이며 실제 주민 정보가 아님
