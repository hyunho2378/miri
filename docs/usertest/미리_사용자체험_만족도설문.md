# 미리 사용자 체험 만족도 설문

> 체험을 마친 참여자가 사용성 척도 10문항과 추가 질문 3개에 답해 미리의 쓰기 쉬움을 같은 기준으로 재고자 함

## 1. 안내

- 참여 번호: P-
- 이름은 적지 않음
- 각 문장에 대해 1(전혀 그렇지 않다)부터 5(매우 그렇다) 가운데 하나를 고름

## 2. 사용성 척도 10문항

| 번호 | 문항 | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|---|
| 1 | 이 서비스를 자주 쓰고 싶을 것 같다 | | | | | |
| 2 | 이 서비스는 쓸데없이 복잡하다 | | | | | |
| 3 | 이 서비스는 쓰기 쉬웠다 | | | | | |
| 4 | 이 서비스를 쓰려면 기술을 잘 아는 사람의 도움이 필요할 것 같다 | | | | | |
| 5 | 이 서비스의 여러 기능이 잘 어우러져 있다 | | | | | |
| 6 | 이 서비스에는 앞뒤가 맞지 않는 부분이 너무 많다 | | | | | |
| 7 | 대부분의 사람이 이 서비스를 금방 익힐 것 같다 | | | | | |
| 8 | 이 서비스는 쓰기 번거로웠다 | | | | | |
| 9 | 이 서비스를 쓰는 동안 자신감이 있었다 | | | | | |
| 10 | 이 서비스를 쓰기 전에 배워야 할 것이 많았다 | | | | | |

- 출처: Brooke, J. (1996). SUS: A quick and dirty usability scale. In P. W. Jordan, B. Thomas, B. A. Weerdmeester, I. L. McClelland (Eds.), Usability Evaluation in Industry (pp. 189-194). Taylor and Francis
- 한국어 문구는 Team 오아시스가 원문 10문항을 옮긴 것으로, 검증 연구를 거친 한국어판이 아님
- 점수 계산(Brooke, 1996): 홀수 문항은 (응답 - 1), 짝수 문항은 (5 - 응답)을 더한 뒤 2.5를 곱해 0~100점으로 환산함

## 3. 추가 질문 3개

|---|---|---|
