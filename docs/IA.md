### 4.1 현황판 `/console`

평시 첫 화면. "지금 산불이 나면 몇 명을 못 옮기는가"에 한 화면으로 답함.

- KPI 4개: 총 부족분 / 대상자 수 / 판독 확인 대기 / 이상 탐지 알림
- 마을별 부족분 표: 동, 마을, 등급별 대상자, 등급별 이송 가능 인원, 부족분. 부족분 내림차순 기본 정렬. 히트맵 보기 전환(마을 × 등급)
- 등급별 부족분 막대 (침상, 휠체어, 부축, 도보)
- 이상 탐지 목록 상위 5건 → 전체는 드로어
- 기준 시나리오 표시: 기본 도달 예측 가정과 준비 시간(부족분 계산 화면 값). 시나리오 바꾸기 링크
- 발령 진행 중이면 첫 화면이 발령 운영 요약으로 바뀌고 상단에 전역 발령 띠

### 4.2 대상자 명부 `/console/roster`

- 필터: 동, 마을, 등급, 판정 출처(AI 판정 / 담당자 입력), 확인 상태
- 표 열: 대상자 코드, 동, 마을, 등급, 특이사항 요약(산소 장비, 보호자 동행 등 태그), 판정 출처, 확인 상태, 갱신일
- 행 클릭 → 우측 드로어: 상세 필드, 판독 근거(EvidencePanel), 변경 이력
- 편집: dah EntityCrud 패턴. 권한 있는 역할에만 InlineEditBar(추가, 일괄 편집) 렌더
- 이름 열 없음. 원본 명부는 지자체 서버 보관 전제(SOURCE B)

### 4.3 서류 판독 `/console/intake`

AI 1번(서류 판독)의 화면. 수기 입력 병목을 없애는 지점.

- 상단 업로더: 사진, 스캔 이미지, PDF. 여러 장 동시. 문서 종류 선택(대피계획서 / 대피카드 / 기타)
- 판독 진행: 문서별 ToolTimeline (문자 인식 → 등급 판정 → 근거 추출 → 원문 대조). G-Chat agent 컴포넌트 재사용
- 확인 대기열: 신뢰도 하 → 중 → 상 순. 행마다 [문서 크롭 | 판정 결과 편집 필드 | 근거 문구]
- 행 동작: 확인 / 수정 후 확인 / 반려(재촬영 요청). 확인된 건만 명부에 확정 반영
- 일괄 확인: 신뢰도 상 건만 허용. 중과 하는 한 건씩

### 4.4 차량과 도우미 `/console/resources`

탭 두 개.

- 차량: 차량 코드, 차종(구급차 / 침상 승합차 / 리프트 승합차 / 승용차 / 마을버스), 등급별 탑승 정원, 소속(소방 / 시청 / 요양시설 / 민간 협약), 협약 상태와 만료일, 대기 위치(동), 가용 여부
- 도우미: 도우미 코드, 담당 마을, 지원 가능 등급, 연락 수단(문자), 최근 응답 여부
- 차종과 등급 호환표는 설정 화면 값 사용 (SOURCE B 이송 등급 표 기준)

### 4.5 부족분 계산 `/console/shortage`

핵심 기능 1(부족분 계산기). 봄철 산불 조심 기간 전 차량 협약 규모를 정하는 근거.

- 입력 패널: 도달 예측 시각(마을별 개별 또는 일괄 "발령 후 8시간"), 준비 시간(기본 1시간), 왕복 시간(마을 → 대피소, 설정 값 불러오기), 추가 협약 차량 가정(차종별 대수)
- 결과: 마을 × 등급 부족분 표, 총 부족분, 필요 추가 차량 산출("리프트 승합차 2대 추가 시 부족분 0")
- 공식 보기 접힘 영역: SOURCE B 부족분 공식 문자 그대로 + 이 계산에 쓰인 값
- 시나리오 저장과 비교(최대 3개). 저장한 시나리오 중 하나를 현황판 기준 시나리오로 지정

### 4.6 발령 운영 `/console/dispatch`

핵심 기능 2(8시간 시계)와 3(배정표). AI 2번(배정 최적화)의 화면. 블루프린트 공백 1(피드백 루프)을 메움.

발령 상태 단계: 평시 → 실행대기 발령 → 배정 확정 → 전송 → 이송 진행 → 종료.

- 평시: 발령 개시 버튼(시 관리자). 훈련 발령 토글(가상 시간 배속, 발표 시연용)
- 실행대기 발령: 마을별 8시간 시계 목록(기한 이른 순). 산불 도달 예측 시각 입력 또는 갱신
- 배정 실행: 배정 최적화 실행 → 배정표(차량 단위 묶음: 차량, 도우미, 대상자 순서, 회차, 예상 완료 시각) + 규칙 순서 대비 비교 + 배정 사유. 수동 조정(드래그로 대상자 이동, dah DragHandle) 후 재검증
- 전송: 도우미별 링크 문자 발송(데모에서는 모의 발송 로그). 도우미 응답 대기 표(수락 / 불가 / 무응답). 불가와 무응답 10분 경과 건은 재배정 대상
- 이송 진행: 실시간 현황표(대상자별 단계: 대기 / 출발 / 도착 / 탑승 / 인계 완료 / 실패). 실패 건은 사유와 함께 상단 고정. 재배정 또는 소방 인계 선택
- 종료: 결과 요약(이송 완료, 미이송, 소요 시간), 도우미 화면 정보 삭제 확인, 이송 기록으로 저장

### 4.7 소방 인계 `/console/handover`

- 미이송자 목록: 대상자 코드, 동, 마을, 등급, 특이사항, 미이송 사유, 위치 정보(발령 중에만 상세)
- 일괄 전달: 인쇄용 화면과 CSV 내보내기(dah ExportButton). 전달 기록(시각, 건수, 수신 기관)
- 발령 중이 아닐 때는 빈 상태

### 4.8 이송 기록 `/console/records`

- 발령별 기록 목록: 일시, 종류(실제 / 훈련), 대상자 수, 완료, 미이송, 소요 시간
- 상세: 마을별 결과, 실패 사유 분포, 도우미 응답 시간
- 마을별 부족분 추이 차트. 차량 협약 규모 산정 근거 리포트(인쇄용)

### 4.9 설정 `/console/settings`

- 기관 정보(기관명, 동 목록, 마을 목록과 산림 연접 여부)
- 대피소 목록과 마을별 왕복 시간
- 차종 등급 호환표와 탑승 정원
- 계산 기본값: 준비 시간, 발령 기준 시간(8시간)
- 사용자와 역할

### 4.10 로그인 `/console/login`

- 기관 계정 로그인. 데모 모드에서는 데모 계정 버튼(시 관리자 / 동 담당자)

## 5. 도우미 면

### 5.1 내 배정 `/h/:token`

- 평시(배정 없음): 대기 일러스트, 담당 마을, "발령 시 이 화면에 배정 표시" 안내
- 배정 도착: 배정 요약(대상자 수, 차량, 대피소) + 수락 / 불가 버튼. 불가 시 사유 칩(연락 불가 거리 / 건강 / 기타)
- 수락 후: 대상자 카드 목록(순서대로). 카드: 순번, 대상자 코드, GradeChip, 주소 상세, 필요 장비와 주의사항, 보호자 연락처(발령 중에만)
- 현재 카드 하단 단계 버튼: 출발 → 도착 → 탑승 완료 → 대피소 인계 완료. 다음 단계 하나만 primary
- 실패 보고(ghost): 사유 칩(부재 / 이송 거부 / 진입 불가 / 상태 악화 / 기타) + 선택 메모 → 담당자 발령 운영 화면 상단 고정
- 종료: 발령 종료 안내 + 배정 정보 삭제 완료 표시. 이후 링크 재접속 시 동일 안내

## 6. 네비게이션 플로우

```
소개 /
  ├─ 담당자 화면 보기 → /console/login (데모 자동) → /console
  └─ 도우미 화면 보기 → /h/demo

평시 흐름 (동 담당자)
  /console/intake 서류 업로드 → AI 판독 → 확인 → /console/roster 반영
  /console/resources 차량과 도우미 등록
  /console/shortage 시나리오 입력 → 부족분과 필요 추가 차량 → 현황판 기준 지정
  /console 현황판에서 부족분과 이상 탐지 확인

발령 흐름 (시 관리자)
  /console/dispatch 발령 개시 → 8시간 시계 → 배정 실행 → 배정 확정 → 전송
    → 도우미 /h/:token 수락 → 단계 보고 → 실패 보고
    → /console/dispatch 실시간 현황 → 재배정 또는 /console/handover 소방 인계
    → 종료 → /console/records
```
