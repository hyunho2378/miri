## A. 컨텍스트 프롬프트 4절 (줄 37~105)

## 4. 미리: 재난취약자 사전 이송 배정

### 한 줄 정의
재난취약자를 대피 기한 안에 옮길 차와 사람이 몇 명분 부족한지 **평시에 계산**하고, 대피 발령 시 **차량과 도우미와 대상자를 묶어 배정**하는 읍면 담당자용 웹 서비스

### 슬로건
**예측이 아니라 역산, 알림이 아니라 부족분**

### 핵심 문제
- 재난 **알림** 체계는 갖춰졌으나 **이송** 체계는 비어 있음
- 재난문자와 안전디딤돌은 걸을 수 있는 사람의 자력 대피를 전제로 함
- 거동 불편자는 알림을 받아도 차와 사람이 도착해야 대피 가능
- 8시간 안에 차와 사람이 충분한지 계산하는 도구가 없음
- 이건 "의료시설 부족" 문제가 아니라 **이송 자원 부족** 문제임 (팀원이 뻔하다고 할 때 이 구분으로 반박)

### 정책 근거
- 행정안전부 「초고속 산불 대비 주민대피 체계 개선방안」(2025.4.16): 위험구역 5시간 전 대피, 재난취약자 **8시간 전** 대피 체계를 지자체에 제시
- 8시간 = 산림청 산불확산예측시스템이 예측한 마을 도달 시각에서 역산한 값

### 사용자와 이해관계자
- 주사용자: 읍면 재난 담당자
- 보조사용자: 대피 도우미, 요양시설 관리자
- 수혜자(비사용자): 재난취약자 본인과 보호자. 설치하거나 조작할 것 없음
- 수신기관: 동해소방서 (미이송자 목록 인계)
- 데이터 제공: 산림청(확산예측), 지자체 명부, 건보공단 장기요양 정보
- 최소 6개 축이 화면 안팎에서 정보, 신뢰, 조정권한, 책임을 주고받는 구조라 단순 앱이 아닌 서비스디자인 대상임

### 핵심 기능 3개
1. **부족분 계산기**: 8시간 안에 옮기지 못하는 인원을 마을별 숫자로 표시. 봄철 산불 전에 민간 차량 협약 규모를 정하는 근거
2. **8시간 시계**: 산림청 도달 예측 시각에서 8시간 역산해 마을별 발령 기한 표시
3. **배정표**: 발령 시 차량과 도우미와 대상자를 묶어 도우미 휴대폰으로 전송

### 이송 등급 4단계
| 등급 | 대상 | 필요 차량과 인력 |
|---|---|---|
| 도보 | 안내만 받으면 스스로 이동 | 마을버스 또는 승용차, 인솔 1명 |
| 부축 | 부축 받으면 승용차 탑승 가능 | 승용차, 도우미 1명 |
| 휠체어 | 휠체어에 앉은 채 이동 | 리프트 승합차, 도우미 2명 |
| 침상 | 누운 상태로만 이송 | 구급차 또는 침상 승합차, 구급대원 |

### 부족분 공식
- 부족분 = 대상자 수 − 8시간 안 이송 가능 인원
- 이송 가능 인원 = 보유 차량 수 × 왕복 가능 횟수
- 왕복 가능 횟수 = (8시간 − 준비 1시간) ÷ 왕복 시간
- 예시: 침상 환자 12명, 침상 차량 2대, 왕복 2시간 → 2대 × 3회 = 6명 이송 가능 → **부족분 6명**

### 배정 규칙
- 이송 난도 높은 침상부터 도보 순으로 차량 배정
- 같은 등급 안에서는 도달 시각 빠른 마을 우선
- 차량 부족 시 미이송자 목록을 소방에 일괄 전달

### AI 역할 (현재 기획서 기준)
- 부족분과 배정은 규칙 기반으로 계산하고 담당자가 결과 검증
- 언어모델은 종이 대피계획서에서 이송 등급을 추출하는 단계에만 사용
- 약점: 서비스디자인 수업 관점에선 AI 역할이 약해 보일 수 있음. 배정 우선순위 결정을 "판단/최적화"로 명확히 언어화하는 보강 필요

### 개인정보 설계
- 명부 원본은 지자체 서버 보관, 클라우드엔 이름 뺀 이송 등급과 마을 코드만
- 도우미 휴대폰엔 본인 담당 대상자만 발령 기간에 표시, 종료 시 삭제
- 기술 스택: React + FastAPI + PostgreSQL

### 유사 서비스와 차별점
| 구분 | 기존 서비스 | 하지 않는 일 |
|---|---|---|
| 알림 | 재난문자, 안전디딤돌, 홍수알리미 | 거동 불편자 이송 |
| 종이 계획 | 산불 취약 특수보호시설 대피계획 가이드라인 | 재가 거주자 포함, 차량 부족 계산 |
| 사람 지정 | 제주 대피 도우미 429명, 충남 안전 파트너 1만 4천여 명 | 8시간 안 이송 가능 여부 판단 |
| 자원 관리 | 재난관리자원 통합관리시스템(KRMS) | 취약자 개인별 차량 배정 |
| 해외 | 일본 NEC 피난 지원 서비스(2024.2) | 시간 제약 계산과 부족분 산정 |

## 5. 왜 동해인가 (선정 배경, 검증 완료)

1. **실제 피해 당사자**: 2022년 3월 강릉 옥계에서 난 산불이 동해로 번져 "2022년 강릉-동해 산불"로 불림. 동해 시가지까지 불길이 들어옴 (강원일보, 아주경제 보도 확인)
2. **구조적 결핍**: 119 구급차 6대(강원소방본부 2025.1)로 산림 연접 마을 18개소(동해시 2024.12)의 침상 환자를 동시에 옮길 수 없음
3. **시의성**: 2026년 1월 동해시가 강릉, 속초, 인제와 함께 **인구감소관심지역**으로 신규 지정됨. 강원 내 삼척, 고성, 양양은 이미 한 단계 위인 "인구감소지역". 즉 동해는 위기가 확정되기 전 단계라 "미리"라는 서비스 원칙과 시점이 일치
4. 실행 근거(보조로만): 팀이 동해시청과 AI 데이터센터 TF 인터뷰 경로 보유. **이걸 선정 이유 1번으로 앞세우면 안 됨**. 접근 가능해서 골랐다는 편의 논리로 들림

### 동해시 현황 수치
- 65세 이상 23.6% (동해시 2024.1), 전국 20.0% (행안부 2024.12)
- 등록 장애인 3,080명 (동해시 2024.1)
- 노인장기요양 인정자 3,120명 (국민건강보험공단 2023.12)
- 노인요양시설 12개소, 재가장기요양기관 38개소 (건강보험심사평가원 2024.6)

### 문제 근거 수치 (기획서에서 가져옴, 원문 링크 재확인 필요)
- 스스로 준비할 수 없어 대피를 포기한 비율 57.7% (국립재난안전연구원 2026.9.2)
- 2025년 영남 산불 대피 과정 사망 31명 중 60대 이상 28명(90.3%) (중앙재난안전대책본부 2025.3)
- 2022년 울진 삼척 산불 당시 요양시설 전용 이송 차량 부족으로 구급차, 경찰 순찰차, 군 수송 버스가 뒤섞여 투입됨

### 기획서에서 고쳐야 할 오류 두 개
1. "여름 호우 인명 피해 사망 23명 실종 9명"은 동해 고유 수치가 아님. 대설과 호우는 동해 전용 근거가 없으니 1차 근거는 산불에 집중하고 다중재난은 확장 톤으로 낮출 것
2. 성장전략 "3단계 인구감소지역 89개 시군구"와 동해 지위가 안 맞음. 동해는 인구감소지역이 아니라 관심지역임. "인구감소지역 및 관심지역을 포함한 소멸위험권역"으로 정정

## 7. 서비스디자인화하면서 드러난 공백 (다음 작업 대상)

기획서는 공모전 사업계획서로는 완성형이지만 서비스디자인으로는 절반. 기능은 나열됐는데 사람들 사이에서 서비스가 어떻게 작동하는지가 비어 있음.

### 서비스 블루프린트 초안
| 단계 | Frontstage | Backstage | 공백 |
|---|---|---|---|
| 평시 | 담당자 PC: 마을별 부족분 숫자 | 명부와 차량 입력, 자동 계산 | |
| 확산 예측 발령(8시간 전) | 담당자 PC: 8시간 시계 | 산림청 예측 수신, 발령 기한 역산 | |
| 위험구역 발령(5시간 전) | 도우미 휴대폰: 배정표 | 침상부터 도보 순 자동 배정 | |
| 이송 실행 | 취약자와 보호자: 도우미와 차량 도착 | 도우미 현장 이동 | **도착 확인과 실패 피드백 루프 없음** |
| 사후 | 담당자: 완료 기록 | 미이송자 소방 인계 | |

### 우선순위 공백
1. **이송 실행 단계 피드백 루프 없음**: 배정표 전송이 곧 서비스 완료로 설계됨. 도우미 도착과 이송 성공 여부를 되받는 접점 필요 (화면설계 전 결정)
2. **이송 등급 최초 판정 주체 불명**: 명부가 이미 4단계로 정리돼 있다는 보장 없음. 판정하는 사람(사회복지사, 요양보호사)이 숨은 핵심 이해관계자일 가능성 (화면설계 전 결정)
3. **도우미 경험 공백**: 누가 도우미인지, 동기는 뭔지, 배정 거부나 중복 시 어떻게 되는지 없음. 도우미 여정지도가 발표에서 가장 강한 서사가 될 수 있음
4. (낮음) 재난취약자 본인이 "오늘 내가 대상자"라는 걸 언제 아는지. 낯선 사람이 갑자기 오면 거부 반응 가능

### 여정 대비 (발표 서사용)
- 현재: 화재 인지 → 전화로 가용 차량 수소문 → 즉석 판단 배정 → 사후에야 미이송자 파악
- 미리 도입 후: 평시 부족분 확인 → 8시간 시계로 여유 확보 → 규칙 기반 자동 배정 → 미이송자 목록 즉시 소방 전달
