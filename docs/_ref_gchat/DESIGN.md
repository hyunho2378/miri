작성일 2026년 9월 6일. 공공시설 AI 민원 SaaS G-Chat의 프론트엔드 디자인 규칙이다. 동해사이 프로젝트의 DESIGN.md 규율을 이어받되 색과 대상과 화면 종류가 다르므로 여기 적힌 것이 우선한다. 값은 전부 src/tokens.js에 있고 이 문서는 그 값의 역할과 사용 규칙을 적는다. 이 문서와 tokens.js가 다르면 tokens.js를 고치고 이 문서를 맞춘다. 코드에서 hex와 px를 직접 쓰지 않는다.

## 플랫폼

B형 반응형 웹. 320px에서 3840px까지 단일 코드베이스.

두 개의 면이 있다.

- 시민 면. 챗봇 홈과 시설 안내. 모바일 우선. 스마트폰으로 시설 앞에서 열어 보는 상황이 기준이다.
- 관리자 면. 대시보드와 운영 관리. 데스크톱 우선. 1024px 이상이 기준이고 그 아래는 사이드바를 접고 표를 카드로 바꾼다. 768px 미만에서는 읽기만 가능하고 편집 진입을 막지 않되 권장하지 않는다는 배너를 띄운다.

앱이 아니다. 바텀시트 없다. 하단 탭바 없다. 모달은 중앙 다이얼로그, 보조 패널은 우측 드로어다.

## 벤치마크와 톤

네이버 하이퍼클로바X의 첫 화면 구조를 따른다. 흰 배경, 화면 중앙의 큰 입력창 하나, 그 아래 추천 질문, 배경 장식 없음. 대화가 시작되면 입력창이 하단으로 내려가고 대화가 위에서 아래로 쌓인다.

관리자 면은 Linear와 Vercel 대시보드의 밀도를 따른다. 회색 배경 위 흰 카드, 얇은 1px 경계, 숫자는 tabular-nums, 장식 없음.

원칙 세 가지.

- 공공 서비스다. 신뢰가 먼저다. 화려함으로 신뢰를 만들려 하지 않는다. 출처가 보이고 담당자에게 연결되는 길이 항상 보이는 것이 신뢰다.
- 콘텐츠가 주인공이다. 답변 텍스트, 시설 상태, KPI 숫자. UI는 가능한 한 사라진다.
- 사업계획서와 화면이 한 몸이어야 한다. 대시보드 KPI 이름은 사업계획서 4대 가설의 지표 이름과 글자 단위로 같다. 심사위원이 사업계획서를 옆에 두고 화면을 보기 때문이다.

### 시스템 색

**9단계(2026-09-07)에서 KRDS 3색 체계로 전면 재편했다.** 색이 다섯 계열이면 무엇을 봐야 하는지 알 수 없다.
색은 위계다. 강조할 것 하나에만 색을 쓰고 나머지는 전부 무채색이다.

| 층 | 토큰 | 쓰는 곳 |
|------|------|------|
| 주색 | primary #2563EB | 강조가 필요한 딱 하나. 주 데이터 계열, 활성 탭과 메뉴, 링크, 주요 CTA, 1등과 최다, 선택 상태, 진행 중 |
| 무채색 | text-pri/sec/meta/ter, line-sub/def/strong, mute, subtle | 나머지 전부. 보조 데이터, 2등 이하, 정상과 완료와 대기 같은 기본 상태, 표 대부분 |
| 위험 | danger #E11414 | 마감 실패 이슈 오답 미해결 휴관 같은 부정만. 아껴 쓴다 |

`success`(초록)와 `warning`(주황 앰버)과 `info` 토큰은 **삭제했다**. 주황과 갈색과 초록은 화면에 없다.
정보(안내)는 primary 를 그대로 쓴다. 같은 값을 두 이름으로 갈라 두면 어느 쪽을 써야 할지 알 수 없다.

| 역할 | 토큰 | 정색 (HSL) | soft | 글자 | 글자 대 soft | soft 대 page / canvas |
|------|------|-----|------|------|------|------|
| 주목. 인계, 처리 중, 예약됨, 남은 건수 | primary | #2563EB (221,83%,53%) | #D6E4FD | #1E40AF | 6.80:1 | 1.28 / 1.20 |
| 중립. 정상, 자동처리, 완료, 대기, 유지보수 | (무채색) | text-meta 점 | line-def #DDE1E6 | text-sec #3D3F45 | 8.01:1 | 1.31 / 1.22 |
| 위험. 마감, 실패, 미해결, 오답, 휴관 | danger | #E11414 (0,84%,48%) | #FBD8D8 | #C21A1A | 4.61:1 | 1.32 / 1.23 |

9-1(2026-09-07)에서 tint 명도를 한 단계 올렸다. 이전 값(primary-soft #EFF6FF, danger-soft #FEEBEB, 중립 mute)은
흰 배경 위 1.09~1.15, canvas 위 **1.01~1.07** 이라 칩 배경이 바탕에 묻혀 형태가 보이지 않았다.
**배지는 흰 바탕과 회색 바탕 둘 다에서 칩 형태가 보여야 한다.** 세 톤 모두 두 맥락에서 1.20 이상이다.
중립 배지 면은 mute 가 아니라 line-def 다. mute(#F0F2F5)는 canvas(#F5F7FA)와 대비 1.04 라 회색 바탕에서 사라진다.
soft 를 올린 만큼 danger 글자를 #D01818 에서 #C21A1A 로 내려 4.5:1 을 지켰다.

배지와 상태 필은 soft 배경 + 진한 글자 + 작은 정색 점이다(8단계 방식 유지). 정색을 면으로 채우지 않는다.
정색을 배경으로 쓰는 곳은 셋뿐이고 전부 배지가 아니다. primary 버튼과 아바타, danger 버튼과 알림 카운트다.

### 차트 색

**유채색은 주 계열 하나뿐이다.** 나머지 계열은 무채색 명도차로 갈리고, 부정 계열만 danger 를 빌려 쓴다.
파랑을 여러 단계로 쓰면 어느 것이 주 계열인지 알 수 없다.

| 순서 | 토큰 | HEX (HSL) | 흰 배경 대비 | 사용 |
|------|------|-----|------|------|
| 1 | chart-1 | #2563EB (221,83%,53%) | 5.17:1 | 주 계열. 자동처리, 이번 기간, 1등. **유일한 유채색** |
| 2 | chart-2 | #505358 (218,5%,33%) | 7.72:1 | 보조 계열. 인계, 지난 기간, 2등 |
| 3 | chart-3 | #72767E (220,5%,47%) | 4.56:1 | 3계열. 3등 |
| 4 | chart-4 | #8F9299 (222,5%,58%) | 3.12:1 | 4계열과 기타 조각, 비교 기준선과 목표선 |
| 부정 | danger | #E11414 | 4.87:1 | 미해결 추이처럼 부정 데이터 계열. 파선과 함께 쓴다 |
| 히트맵 1~4 | chart-heat-1~4 | #9DBEFB #71A1F9 #4583F7 #2563EB | 1.88 / 2.57 / 3.59 / 5.17 | 단일 파랑 명도 스케일. 0 은 데이터 없음이라 mute |

회색 셋은 기존 무채색 토큰(text, line)과 같은 채도 5% 대다. 채도를 더 주면 파란 회색으로 읽혀 주 계열과 경쟁한다.
상호 대비는 2-3 이 1.69, 3-4 가 1.46, 2-4 가 2.47 이다. 넷 다 흰 배경 3:1 을 넘는다(WCAG 2.2 1.4.11).

강조 규칙. **도넛은 1등만 파랑이고 2등 이하는 회색 명도차**다. **랭크 목록도 1등 막대와 번호만 파랑**이다.
막대 차트는 이번 기간이 파랑, 비교 기간이 회색이다.

색으로만 뜻을 구분하지 않는다. 범례 라벨과 파선 패턴과 점을 항상 같이 둔다.
예약 캘린더처럼 셀 안에 라벨을 넣을 수 없는 자리는 중립을 명도 두 단계로 나눈다(여유 mute, 유지보수 line-def).
그 매핑도 StatusPill 한 파일에 있다(`cellFill`).

## 폰트

Pretendard Variable 단독. fallback 추가 금지.

| Weight | 값 | 사용처 |
|--------|-----|--------|
| ExtraBold | 800 | KPI 숫자 |
| Bold | 700 | 페이지 타이틀, 카드 타이틀, Display, 아바타 이니셜 |
| SemiBold | 600 | 섹션 헤딩, 캡션 라벨, 배지, 버튼, 표 헤더, 탭 |
| Medium | 500 | 네비게이션, 사용자 말풍선 |
| Regular | 400 | 본문, 답변 텍스트, 표 셀, 메타 |

Light 안 쓴다. 관리자 면은 정보 밀도가 높아 300은 읽히지 않는다. 한 화면에 최소 세 weight가 보여야 위계가 선다.

**인접해 놓이는 짝은 최소 200 차이가 난다.** 8단계(2026-09-07)에서 "죄다 얇아서 위계가 안 보인다"는
피드백으로 사다리를 넷으로 벌렸다. 라벨(caption 600) 대 값(kpi 800), 카드 타이틀(h3 700) 대 본문(body 400),
델타(caption 600) 대 보조 문구(meta 400) 다. 400 과 500 만 인접하면 위계가 서지 않는다.

## 타이포그래피

전부 clamp()로 유동. 브레이크포인트에서 점프하지 않는다. tracking과 leading은 크기에 따라 달라진다. 하나의 letter-spacing을 전 크기에 걸지 않는다.

| 역할 | 토큰 | size clamp | weight | tracking | leading |
|------|------|-----------|--------|----------|---------|
| Display. 챗봇 홈 헤드라인 | display | clamp(30px, 2vw + 21px, 42px) | 700 | -0.035em | 1.14 |
| H1 페이지 타이틀 | h1 | clamp(24px, 1vw + 19px, 32px) | 700 | -0.025em | 1.2 |
| H2 섹션 헤딩 | h2 | clamp(18px, 0.5vw + 16px, 22px) | 600 | -0.02em | 1.25 |
| H3 카드 타이틀 | h3 | clamp(17px, 0.3vw + 15.5px, 19px) | 700 | -0.02em | 1.3 |
| KPI 숫자 | kpi | clamp(28px, 1.2vw + 22px, 40px) | 800 | -0.03em | 1.05 |
| Body 답변 본문 | body | clamp(15px, 0.2vw + 14px, 17px) | 400 | -0.01em | 1.7 |
| Body Small. 표 셀, 카드 설명 | body-sm | clamp(13px, 0.15vw + 12.5px, 14px) | 400 | -0.005em | 1.55 |
| Caption. 라벨, 배지 | caption | clamp(11px, 0.1vw + 10.5px, 12px) | 600 | 0 | 1.4 |
| Meta. 출처, 시간 | meta | 12px 고정 | 400 | 0.01em | 1.4 |
| Count. 알림 카운트 전용 | count | 10px 고정 | 700 | 0.01em | 1 |

8단계에서 큰 활자는 크기 하한을 올리고 자간을 좁혀 덩어리감을 줬고(display h1 h3 kpi),
캡션 라벨을 500 에서 600 으로, KPI 숫자를 700 에서 800 으로 올렸다. 폰트는 Pretendard 그대로다.
count 는 알림 인디케이터가 16px 원 안에 들어가야 해서 만든 유일한 고정 10px 이다.

답변 본문 leading 1.7은 고정이다. 한글 장문이 이보다 좁으면 읽기 속도가 떨어진다.

숫자는 항상 tabular-nums. KPI, 표, 시간, 카운트 전부.

## 그림자

동해사이는 그림자를 금지했다. G-Chat 관리자 면은 회색 캔버스 위 흰 카드라 경계만으로도 서지만, 떠 있는 요소(드로어, 모달, 드롭다운, 토스트)는 그림자 없이는 층이 안 보인다. 그래서 두 단계만 허용한다.

| 토큰 | 값 | 사용처 |
|------|-----|--------|
| card | 0 0 0 1px rgba(16,16,16,0.06) | 카드 경계 대용. border 대신 ring |
| float | 0 4px 12px -2px rgba(16,16,16,0.10), 0 12px 32px -8px rgba(16,16,16,0.16) | 드로어, 모달, 드롭다운, 토스트 |

시민 면 챗봇 화면에는 float를 쓰지 않는다. 그림자로 카드를 꾸미지 않는다.

## 브레이크포인트

```
xs 320 / sm 390 / md 768 / lg 1024 / xl 1280 / 2xl 1440 / 3xl 1920 / 4xl 2560 / 5xl 3840
```

브레이크포인트는 구조 변화에만 쓴다. 열 수, 사이드바 유무, 표를 카드로 바꾸는 시점. 크기 변화는 clamp와 minmax로 한다.

### 구조 변화 표

## 아이콘과 일러스트

아이콘은 lucide-react 단독. 크기 16 20 24 32 48 다섯 단계. 색은 텍스트 토큰만. stroke 1.75 고정.

에이전트는 다른 아이콘 라이브러리를 도입하지 않는다. 필요하면 현호가 승인한다.

일러스트는 unDraw만. 빈 상태, 로그인, 404에만. 색은 primary 단색으로 바꿔 SVG로 public/images/illustrations/에 둔다. 시설 카드와 상세와 대시보드에는 일러스트를 넣지 않는다.

시설 사진은 실사 jpg. 별점 리뷰수 금지. 사진 없는 시설은 mute 배경에 시설 유형 아이콘 24로 채운다.

## 모션

Apple HIG 기준. transform과 opacity만 애니메이션한다. width height top left margin padding을 애니메이션하지 않는다.

### 토큰

| 토큰 | 값 | 사용 |
|------|-----|------|
| duration-fast | 120ms | 색 변화, 아이콘 전환 |
| duration-base | 200ms | 버튼 hover 배경, 탭 인디케이터, 칩 |
| duration-enter | 240ms | 메시지 진입, 카드 진입, 드로어 |
| duration-page | 320ms | 페이지 전환, TopNav 폭 전환 |
| ease-out | cubic-bezier(0.16, 1, 0.3, 1) | 진입, 확장 |
| ease-in-out | cubic-bezier(0.65, 0, 0.35, 1) | 위치 이동 |
| ease-standard | cubic-bezier(0.2, 0, 0, 1) | 색과 opacity |
| spring-press | scale(0.97) 120ms ease-out | 버튼 press |

### 차트 표현 규율 (7단계)

| 요소 | 규칙 |
|------|------|
| 꺾은선 | stroke 2.5px. 파선(미해결) 2px. monotone cubic 으로 눕힌다. 일반 스플라인은 오버슈트로 0 아래 가짜 골짜기를 만든다 |
| 데이터 포인트 | 반지름 3.5 원. 계열색 채움 + page 색 1.5px 테두리. 점 간격이 24px 미만이면(분기 같은 긴 구간) 마커를 그리지 않는다 |
| 면 채움 | 주 계열 하나만. 계열색 단색에 fill-opacity 0.1. 그라데이션 금지는 그대로다 |
| 막대 | 최대 폭 72, 그룹 폭의 78%. radius 4 |
| 도넛 | 링 두께 30, 조각 간격 5px 고정, 시작각 12시. 조각이 하나면 간격 0. stroke-linecap 은 butt 다. 둥근 캡은 양 끝에 STROKE/2 씩 더 그려 간격을 보이게 하려면 조각마다 35px 넘게 잘라야 하고 네 조각이면 원의 30% 가 사라진다 |
| 히트맵 | 단계 색은 chart-heat-1~4. 0 은 mute |
| 진입 | 최초 1회. reduced-motion 이면 전역 규칙이 0.01ms 로 만들어 즉시 최종 상태 |

| 효과 | 값 | 대상 |
|------|-----|------|
| 페이지 진입 | opacity 0→1, translateY 8→0, page/ease-out | 라우트 전환 |
| 메시지 진입 | opacity 0→1, translateY -6→0, enter/ease-out | 새 말풍선, 답변 행 |

| press | scale 0.97, fast | 버튼 |
| 스켈레톤 | background-color 두 회색 사이, 1.4s ease-in-out 무한 | 답변 대기 바 |

| KPI 숫자 | 0→값 카운트업 400ms, 최초 1회만 | 대시보드 |

### 금지

- hover에 scale. 레이아웃 흔들림
- hover에 translateY로 떠오르는 효과. 카드 그리드에서 산만함
- 무한 반복 장식 애니메이션. 스켈레톤 제외
- 자동 스크롤로 사용자가 읽고 있는 위치를 끌어내리는 것. 새 질문 상단 앵커만 허용, 스트리밍 중 바닥 추적 금지
- 스트리밍 중 근거 카드 노출. 답변 끝난 뒤에만
- parallax, 3D, WebGL, backdrop-blur

### 접근성 대응

prefers-reduced-motion: reduce 시 전 애니메이션 0.01ms. 스크롤 behavior auto. 카운트업 없이 최종값 즉시.
prefers-reduced-transparency 시 드로어 배경 딤을 불투명 회색으로.
prefers-contrast: more 시 line-sub를 line-def로, text-meta를 text-sec로 올린다. tokens.js에 contrast 변형을 둔다.

## 접근성

WCAG 2.2 AA.

- 모든 인터랙티브 요소 키보드 도달. 탭 순서는 시각 순서와 같다.
- focus-visible 2px primary offset 2px 전역.
- 터치 타깃 최소 44x44 모바일(가로도 44). 프리미티브가 `min-h-11 min-w-11 md:min-h-0 md:min-w-0` 로 강제하고 md 이상은 데스크톱 밀도를 유지한다.
  예외는 문장 안 인라인 링크와 보이는 라벨이 대신 타깃이 되는 sr-only 파일 입력뿐이다(9-2에서 390px 25경로 실측).
- 텍스트 대비 4.5 이상. 위 텍스트 표의 대비값 기준. text-ter는 정보 텍스트 금지.
- 상태를 색으로만 전하지 않는다. 필과 배지는 항상 텍스트 라벨 동반.
- 스트리밍 답변 영역 aria-live polite. 스켈레톤은 `role="status" aria-live="polite"` 로 불러오는 중임을 알린다(막대는 aria-hidden).
- 오류는 `role="alert"` 과 재시도 수단을 함께 둔다. 서버 오류를 빈 결과로 위장하지 않는다.
- aria-label 도 번역 대상이다. 속성에 문자열을 하드코딩하지 않는다.
- 이미지 alt 필수. 장식 이미지는 alt 빈 문자열.
- 폼 라벨 association 필수. placeholder를 라벨 대용으로 쓰지 않는다.
- 언어 전환 시 html lang 갱신.

## 콘텐츠 규칙

### UI 텍스트

- 명사형 명령으로 통일. 예약 상태 확인, 담당자 연결, 문서 업로드. 동사형과 혼용하지 않는다.
- 가운데점 줄표 이모지 이탤릭 금지.
- 기관명은 하드코딩하지 않는다. VITE_ORG_NAME과 설정 화면 값에서 온다. 화면에 동해시가 박혀 있으면 두 번째 기관에 팔 수 없다.
- 심사용 화면이니 사업계획서 용어를 그대로 쓴다. 민원 자동처리율, 응답 정확도, 담당자 응대시간, 이용자 만족도(NPS). 다른 말로 바꾸지 않는다.

### AI 답변 텍스트 (렌더러 규칙)

백엔드가 무엇을 보내든 프론트가 정제한다. lib/stripMarkdown.js는 동해사이 검증 완료 로직을 그대로 가져온다.

- 제목 기호와 백틱 제거, 별표 불릿을 하이픈 불릿으로, 홑별표 강조를 볼드로 승격, 짝 없는 별표 제거, 스트리밍 중 미완성 볼드 감춤, 볼드 뒤 조사 받침 교정.
- 렌더러는 문단 / 하이픈 불릿 / 번호 목록 / 파이프 표 / 볼드를 그린다. 그 외 마크다운은 지원하지 않는다.
- 답변 톤: 공식 안내 톤. 해요체가 아니라 합니다체. 시설관리공단 안내문과 같은 톤이어야 시민이 공식 안내로 받아들인다. 이 규칙은 백엔드 시스템 프롬프트에 넣어야 하며 API_CONTRACT.md에 적는다.

### 근거 표시

답변 하단 근거 카드는 출처 문서명, 문서 종류(운영 매뉴얼 / 공지 / FAQ / 예약 시스템), 갱신일을 보인다. 요구사항 두 번째(이게 공식 안내가 맞나 싶다)에 대한 답이다. 갱신일이 90일 넘으면 text-sec 굵은 글자로 오래된 자료일 수 있음을 붙인다. 9단계에서 경고색을 없앴다.

### 담당자 연결

모든 답변 액션 바에 담당자 연결 버튼이 항상 있다. 신뢰도가 낮거나 자료가 없을 때만 나오는 게 아니다. 요구사항 세 번째(AI가 못 풀면 바로 사람에게)는 사용자가 판단할 권리를 주는 것이다. 누르면 HandoffCard가 답변 아래 인라인으로 열려 부서 전화와 운영시간, 문의 남기기 폼을 보인다.
