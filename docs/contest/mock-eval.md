## 위원별 의견 요약

### 1. 재난안전 공무원

평시 부족분 계산과 발령 시 차량 배정이 재난 대응 목적과 연결된다. 다만 산불 확산 속도와 차량, 도우미 수가 가정이며, 동해시 실제 도달 시각 연계는 협의 전이다. 차량 협약 비용, 보험, 침상 이송 인력 조건도 비어 있다. 협력 요청서는 작성됐으나 발송, 회신 실적은 없다.

### 2. 공공 AI 전문가

현장 소식 기능에서 AI는 변경 후보와 근거를 제안하고, 규칙은 계산하고, 담당자는 승인한다. 원문에 없는 인용을 낮은 신뢰도로 처리하는 안전장치가 있다. 다만 `GEMINI_API_KEY`가 없어 실제 AI 결과는 없다. 합성 평가의 예측값도 코드에 직접 적은 시연값이며 실제 모델 호출 결과가 아니다. 평가 기능은 정확도 입증에 쓰이지 않는다.

### 3. 클라우드, 데이터 엔지니어

플랫폼 카탈로그 조사에서 형식, 갱신주기, 세부 필드, 승인 조건이 실제 화면에 없다는 점을 분리해 적은 것은 신뢰를 높였다. 기존 공공데이터포털 직접 연계와 플랫폼 경유 연계도 구별했다. 승인 대기라 플랫폼 호출은 0건이다. 실제 원본 응답, 운영환경 검증이 남았다.

### 4. 사회혁신 연구자

문제 정의와 책임 경계는 명확해졌고, 문서에 모의 응답 한계도 표시했다. 시민, 도우미, 시설의 실제 목소리가 없고 As-Is가 확정되지 않았다. 협조 요청서 발송과 회신이 확인되지 않아 협력성은 낮게 유지했다. 대상자와 가족의 방문 수용, 도우미 참여 의향도 미검증이다.

### 5. 서비스디자인 교수

업무 흐름과 화면 구현은 풍부하지만, 설계자 가정과 사용자 근거를 구별해야 한다. 현장 소식 평가기는 실제 모델을 검증하지 않는다. 291명에서 267명으로 줄어든 값과 추가 차량 20대는 가상 입력에서 나온 값이라 현장 성과로 쓰면 안 된다. 출처와 숫자 기준을 한 표로 통일할 필요가 있다.

## 미해결 위험

- 인터뷰와 사용성 평가는 미진행 상태다.
- 민관협력 지원 플랫폼은 승인 대기 상태다. 데이터/API 호출과 플랫폼 협력 실적은 없다.
- Gemini 키가 연결되지 않아 서류 읽기와 현장 소식 판독은 실제 모델 응답이 아닌 모의 응답이다.
- 합성 평가 수치는 긴급 누락률 2/4, 상태 분류 6/8, 근거 일치 6/7이다. 정답과 예측을 직접 작성한 시연값이라 모델 정확도로 인용하지 않는다.
- PLAN.md와 상세기획서 PDF 사이의 숫자, 출처 차이를 해결하지 않았다.
- 실제 서류 이미지를 Gemini에 보내는 코드 흐름과 "거동 문구만 전송"이라는 제출 문서 설명이 불일치할 수 있다. 공개 제출 전 반드시 고친다.
- 도식, 화면 캡처의 시각적 품질은 사례집 텍스트 추출만으로 확인하지 못했다.
