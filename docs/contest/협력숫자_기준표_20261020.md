# 협력과 개발 숫자 기준표 (2026. 10. 20. 기준)

상세기획서 v5, 참고자료 v2, 개발보고서가 모두 이 표의 값을 씀. 원자료를 다시 세어 정함.

## 1. 협력 단계 정의

- ① 연락: 서면 자문 메일을 보낸 곳
- ② 회신: 답을 받은 곳(수신처 안내, 일정 회신, 내부 전달, 보류 포함)
- ③ 의견이나 자료를 받음: 검토 의견, 자료, 지침, 경로 안내, 전문가 소개를 받은 곳
- ④ 반영: ③에서 받은 것이 기획서 설계나 시안 화면을 바꾼 곳(④는 ③에 포함)
- 셈 단위는 응답 주체(사람 또는 창구). 같은 곳이 메일과 전화로 함께 답하면 1곳
