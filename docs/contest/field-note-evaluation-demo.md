# 현장 소식 판독 평가 시연

> **시연용 합성 응답 결과. 실제 사용자 자료, 실제 AI(HyperCLOVA X) 응답, 모델 성능 측정값이 아니다.** 상세기획서에는 실제 서류 판독 검증이 예정으로 적혀 있다. 실제 검증 전에는 아래 결과를 성능 수치로 인용하지 않는다.

## 평가 실행

```sh
cd client
node scripts/evaluate-field-notes-demo.mjs
```

평가 로직은 `client/src/lib/noteEvaluation.js`, 합성 응답 8건은 `client/scripts/evaluate-field-notes-demo.mjs`에 있다. 현장 소식의 민감정보를 사용하지 않는다.

## 시연용 결과

| 평가 기준 | 결과 | 분모 | 해석 |
|---|---:|---:|---|
| 긴급 누락률 | 2/4, 50% | 정답 라벨상 긴급한 사례 4건 | 합성 긴급 사례 중 예측 결과에서 긴급 표시가 빠진 비율 |
| 상태 분류 정확도 | 6/8, 75% | 상태 라벨이 있는 사례 8건 | 기대 상태와 예측 상태가 일치한 비율 |
| 원문 근거 일치율 | 6/7, 85.7% | 근거 문구 평가 대상 7건 | 예측 근거 문구가 원문에 그대로 포함된 비율 |

## 계산 규칙

- 긴급 누락률 = 긴급 정답 중 예측에서 긴급으로 표시되지 않은 건수 ÷ 긴급 정답 건수
- 상태 분류 정확도 = 예측 상태가 기대 상태와 같은 건수 ÷ 상태 분류 대상 건수
- 원문 근거 일치율 = 정규화한 예측 근거 문구가 원문에 포함된 건수 ÷ 근거 평가 대상 건수
- 정답, 예측 문장과 상태는 전부 합성으로 만든 시연값이다. 이 분수는 실제 서비스 성능을 추정하지 않는다.

## 실제 검증을 위한 기록 양식

| 익명 사례 코드 | 정답 상태 | 모델 제안 상태 | 정답 긴급 여부 | 모델 긴급 표시 | 근거 원문 포함 여부 | 담당자 확정 결과 |
|---|---|---|---|---|---|---|
| 실제 검증 뒤 기입 | 실제 서류 검토로 라벨 | HyperCLOVA X 호출 결과 기록 | 재난안전 담당자 검토 | 판독 결과 기록 | 원문과 문자열 대조 | 담당자 판단 기록 |

실제 검증을 시작하기 전에 개인정보 처리 근거, 참여자 동의, 익명화, 표본 선정, 정답 라벨 작성자를 정한다. 담당자와 시설 자문을 거친 실제 서류를 확보하기 전에는 정확도 주장을 하지 않는다. 긴급 누락을 특히 확인하고, 결과를 배포나 운영 승인 근거로 단독 사용하지 않는다.
