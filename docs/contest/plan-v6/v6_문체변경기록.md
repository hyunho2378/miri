# 상세기획서 v5 → v6 문체 변경 기록 (2026. 10. 21.)

구조 변경
- 장 순서(Ⅰ~Ⅶ, 별첨 출처) 유지, 각 장 안을 `1-1. 절` > 굵은 소제목 > 핵심 주장(ㅇ) > 근거(-) 구조로 변경

- 삭제: 화면 캡션마다 반복되던 "가상 자료" 고지(머리표 '시연 자료' 한 줄로 통합), 확인 못 한 일과 가정 고지 문장(로드맵과 일정 표로 이동)
- 숫자와 사실, 그림 23개, 출처 17건 변경 없음
